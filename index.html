연수 당일, 계정 만드느라 첫 시간을 쓰지 않으려면.

실습에는 크롬 브라우저와 구글 개인계정이 필요합니다. 아래 8단계를 미리 마쳐 두시면 첫 시간부터 바로 실습에 들어갑니다.

STEP 1
크롬 브라우저가 없다면? 크롬 설치

이 연수는 크롬(Chrome) 기준으로 진행합니다. 엣지에서는 실습 중 일부 기능이 아예 나타나지 않아요.

⬇️ 크롬 설치하기
  1. ‘크롬 설치하기’ 버튼 → 열린 화면에서 ‘Chrome 다운로드’를 누릅니다

    빨간 네모 안의 파란 버튼을 누르세요

  2. 파일을 저장하는 창이 뜨면 이름은 그대로 두고 ‘저장’을 누릅니다

    이 창이 뜨지 않고 바로 다운로드되면 다음 단계로 넘어가세요

  3. 화면 오른쪽 위(또는 아래)에 뜨는 다운로드 표시에서 ChromeSetup.exe를 누릅니다

    오른쪽 위 다운로드 아이콘(↓)을 누르면 목록이 열려요. 안 보이면 파일 탐색기 → 다운로드 폴더에서 ChromeSetup을 더블클릭하세요

  4. “이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?” 창이 뜨면 ‘예’
  5. 설치는 알아서 진행돼요. 잠시 기다리면 크롬 창이 저절로 열립니다
  6. 작업표시줄에 크롬이 없다면: 크롬이 열린 상태에서 아래 아이콘을 마우스 오른쪽 클릭 → ‘작업 표시줄에 고정’
💡 이미 크롬이 있는지 모르겠다면? 윈도우 시작 버튼을 누르고 chrome을 입력해 보세요. ‘Google Chrome’이 나오면 설치할 필요가 없어요.
STEP 2
쓰시던 구글 개인계정에 로그인할 수 있는지 확인

다음 단계에서 저장공간을 확인하려면 먼저 쓰시던 개인계정으로 로그인이 되어야 해요. 크롬에서 로그인이 되는지 확인해 주세요.

🔑 기존 아이디·비밀번호 찾기

“이 번호로 만든 계정이 있었던 것 같은데…” 싶을 때, 구글 공식 방법으로 찾을 수 있어요.

  1. 이메일 찾기 페이지 열기 — 구글 로그인 화면의 아이디 입력칸 아래 ［이메일을 잊으셨나요?］를 누르거나 아래 버튼을 누르세요.
    🔍 구글 이메일 찾기
  2. 휴대전화 번호 입력 — 계정에 연결했던 번호를 입력하고 ［다음］ (국가 번호가 +82인지 확인)
  3. 인증 코드 입력 — 휴대전화 문자로 온 6자리 코드를 입력합니다.
  4. 이름 입력 → 계정 확인 — 계정에 등록했던 성·이름을 정확히 입력하면, 그 번호로 가입된 구글 이메일 목록이 나타나요.
  5. 비밀번호가 기억 안 나면 — 찾은 이메일로 로그인 화면에서 ［비밀번호 찾기］ → 휴대전화 인증 후 새 비밀번호를 설정하세요.
    🔑 구글 비밀번호 찾기(계정 복구)

💡 이름은 가입할 때 적은 그대로(성·이름 칸 구분)여야 찾아져요. 번호를 바꾼 뒤 계정에 새 번호를 등록하지 않았다면 이 방법으로는 찾기 어려워요.

❌ 기관계정(goedu 등)으로는 제미나이 등 일부 AI 실습이 막힐 수 있어요. 실습은 반드시 개인계정으로 진행합니다.
STEP 3
그 계정의 드라이브 저장공간 확인
⚠️ 쓰시던 계정은 드라이브가 가득 찬 경우가 많아요. 구글 포토에 휴대폰 사진이 자동 백업되면서 저장공간을 다 쓰면, 연수 중 실습이 아예 되지 않습니다.
💾 내 저장공간 확인하기
✅ 여유가 넉넉하다면 — 대략 5GB 이상 남아 있으면 이 계정으로 실습하세요. STEP 4는 건너뛰세요.
🆕 거의 다 찼다면 — STEP 4에서 연수용 새 계정을 하나 만들어 오세요. 사진은 지우지 않으셔도 됩니다.

휴대폰 사진이 구글 포토에 자동 백업되면서 저장공간(15GB)을 다 쓰고 계신 분이 많습니다. 저장공간이 없으면 연수에서 자료를 만드실 때 에러가 납니다. 사진을 지우실 필요 없이, 연수용 계정을 하나 새로 만들어 오시면 됩니다.

💡 사진을 정리하고 싶으시다면 구글 포토에서만 지우고 휴대폰에는 남기는 방법이 있어요. 다만 휴대폰 백업을 끈 상태를 유지해야 하고, 백업을 다시 켜면 사진이 다시 올라가거나 휴대폰 사본이 지워질 수 있어요. 지운 사진은 휴지통에 30일간 남아 있어요. 연수 준비로 하실 필요는 없고, 여유 있을 때 공식 안내를 보며 천천히 해 주세요.

STEP 4
저장공간이 부족한 분만 — 새 구글 계정 만들기

STEP 3에서 저장공간이 거의 다 찼던 분만 해 주세요. 여유가 넉넉했다면 넘어가시면 됩니다.

📅 가입할 때 생년월일을 정확히 입력해 주세요. 잘못 입력해 미성년자로 등록되면 제미나이를 쓸 수 없고, 되돌리려면 신분증 등으로 연령 확인을 해야 할 수 있어요.
✏️ 새로운 구글 계정 만들기
📷 구글 계정 만들기 — 화면 따라 하기 (15단계)

위 버튼을 누르면 아래 화면이 차례대로 나옵니다. 눈에 보이는 대로만 따라오시면 돼요.

  1. 성·이름 입력 — 성은 선택사항이라 이름만 적어도 됩니다.
  2. 기본 정보 — 생년월일과 성별을 고릅니다. 생년월일은 꼭 정확하게! 잘못 넣어 미성년자로 등록되면 제미나이를 쓸 수 없어요.
  3. 이메일 주소 만들기 — 구글이 추천해 준 주소 중 하나를 고르는 게 가장 편합니다.
  4. 직접 만들고 싶다면 — ［내 Gmail 주소 만들기］에 원하는 주소를 적습니다. 이미 있는 주소라고 나오면 숫자를 바꿔 여러 번 시도하면 됩니다.
  5. 안전한 비밀번호 만들기 — 본인 이름 영어 + 숫자 + 기호 조합이 쉬워요. (예: dldowls1234!) 아래 칸에 똑같이 한 번 더 입력합니다.
  6. 보안문자 입력 — 본인 휴대전화 번호를 넣고 ［다음］을 누릅니다.
  7. 받은 코드 확인 — 문자로 온 G- 뒤의 6자리 숫자를 그대로 입력합니다.
  8. 복구 이메일 추가 — 기존에 쓰던 메일 주소를 적습니다. 건너뛰기도 가능합니다.
  9. 복구 연락처 추가 — 앞에서 쓴 복구 이메일과 같은 주소를 써도 됩니다. 건너뛰기도 가능합니다.
  10. 계정 정보 검토 — 만들어진 주소를 확인하고 ［다음］.
  11. 개인 정보 보호 및 약관 — 맨 아래 체크 두 칸을 누른 뒤 ［계정 만들기］를 누릅니다.
  12. 완성! — 계정 첫 화면입니다. 노란 박스의 ［복구 전화번호 추가］까지 해 두시면 비밀번호를 잊어도 안전해요.
  13. (선택) 복구 옵션 더 채우기 — 앞 화면의 ［복구 전화번호 추가］를 누르면 복구 옵션 화면이 나옵니다. 복구 이메일 옆 ✏️를 누르고 주소를 확인한 뒤 ［코드 전송］.
  14. 코드 입력칸이 나타납니다 — 이메일로 받은 6자리 숫자를 여기에 넣으면 돼요. 건너뛰기도 가능합니다.
  15. Gmail에서 코드 확인 — 복구 이메일의 받은편지함에 온 「복구 이메일 설정 코드」 메일의 6자리 숫자를 그대로 옵겨 넣고 ［인증］을 누릅니다.
📝 만드신 아이디와 비밀번호는 꼭 종이에 적어 연수 날 가져오세요.

만드는 데 3~5분이면 됩니다. 휴대폰 문자 인증만 하시면 끝나요. 만드신 뒤에는 아이디와 비밀번호를 꼭 적어 두세요.

    4. 계정별 프로필 사진 변경 / 테마 색상으로 구분 → 어느 계정인지 한눈에🙂 프로필 사진 만들기 (Notion Faces)

  • ② 초간단 즐겨찾기 + 파비콘 만들기▾
    1. 미션: 웹교안 · 제미나이 · 내가 자주 가는 사이트를 즐겨찾기 하고 아이콘(파비콘)만 3개 남기기
    2. 주소창 오른쪽 별표(☆)로 즐겨찾기 대신 추파춥스(?) 활용하기!

      🔗chrome://settings/appearance
      단축키도 메뉴 찾기도 필요 없어요.
    2. 새 탭 열어보기 — Ctrl+T. 크롬은 새 탭 화면에서는 즐겨찾기바를 자동으로 보여줍니다. 거기서 우클릭 → ［북마크바 표시］를 켜면 모든 화면에서 보여요
    3. 메뉴로 — 오른쪽 위 ⋮ → 북마크 및 목록 → ［북마크바 표시］
      ▲ ① 오른쪽 위 ⋮ → ② 북마크 및 목록 → ③ 북마크바 표시 (빨간 네모 순서대로)
    4. 단축키 — Ctrl+Shift+B (갤럭시북에서는 안 될 수 있어요 — 아래 참고)
    💡 "안 보인다"는 분의 절반은 그냥 일반 페이지에 계신 겁니다. 새 탭부터 한번 열어보시게 하세요.
    ⌨️ Ctrl+Shift+B를 눌러도 안 될 때 — 삼성 갤럭시북이라면
    갤럭시북에는 삼성 앱이 이 단축키를 먼저 가져가는 경우가 있어요. 눌러도 즐겨찾기바는 안 나오고 엉뚱한 창이 뜨거나 아무 반응이 없다면 이 경우입니다.
    ✅ 급할 땐 이것만 — 단축키를 안 쓰면 됩니다
    1. 주소창 바로 아래 빈 곳에서 마우스 우클릭 → ［북마크바 표시］
    2. 또는 오른쪽 위 ⋮ → 북마크 및 목록 → ［북마크바 표시］
    🔴 이 방법은 어느 노트북에서든 됩니다. 연수 중이라면 여기까지만 하고 넘어가세요. 아래는 연수 끝나고 천천히 하시면 됩니다.
    1단계 · 범인부터 확인 (빅스비 잠시 끄기)
    1. 화면 우측 하단 작업 표시줄(시계 옆)에서 ∧ (숨겨진 아이콘 표시) 화살표 클릭
    2. 파란색 Bixby 아이콘을 마우스 오른쪽 버튼으로 클릭 → ［종료］ 선택
    3. 크롬으로 돌아가 Ctrl+Shift+B를 눌러 봅니다
    💡 여기서 즐겨찾기바가 나왔다면 범인은 빅스비입니다 → 2단계로 가세요.
    그래도 안 되면 빅스비가 아닙니다. 다른 삼성 앱일 수 있으니 붙들지 마시고 위의 우클릭 방법을 쓰세요.
    💡 메뉴 이름이 ［종료］가 아니라 ［끝내기］로 보일 수도 있어요. 같은 뜻입니다.
    2단계 · 영구 해결 (시작 프로그램에서 제외)
    1. Ctrl+Shift+Esc를 눌러 작업 관리자를 엽니다
    2. 왼쪽 메뉴에서 ［시작 앱］ 탭을 클릭합니다 (속도계 모양 아이콘)
    3. 목록에서 Bixby를 찾아 우클릭 → ［사용 안 함］
    4. PC를 다시 시작하면 그다음부터는 충돌이 없습니다
    ⚠️ 시작 앱에서 끄면 빅스비 음성 호출도 안 됩니다. 빅스비를 쓰신다면 1단계만 하시고, 필요할 때마다 종료해 주세요.
    💡 업무용 PC라 설정이 잠겨 있다면 맨 위의 우클릭 방법을 쓰세요. 결과는 똑같습니다.
  • ③ 즐겨찾기 폴더로 정리 (업무별로 묶기)▾
    매일 들어가는 곳은 정해져 있죠 — 업무포털, 나이스, 교육청 홈페이지. 즐겨찾기바에 업무별 폴더를 만들어 두면 그 안에 다 들어갑니다. 한 번 만들면 계속 쓰고, 로그인만 하면 다른 PC에서도 따라옵니다.
    즐겨찾기바 빈 곳 우클릭 → 폴더 추가 → 이름 입력 → 저장
    🔴 저장 위치는 ［북마크바］로 두세요. 그래야 화면 위에 바로 보입니다.
    이렇게 즐겨찾기바에 폴더가 생깁니다.
    ▲ 이런 식으로 업무별 폴더를 나란히 만들어 두고, 그 안에 사이트를 넣으면 됩니다.
    1. 같은 방법으로 내 업무에 맞는 폴더 2~3개를 만듭니다 (예: 업무 · 복무·연수 · 자료)
    2. 자주 가는 사이트를 연 뒤 주소창 오른쪽 ★(별표) 클릭 → 폴더를 골라 저장
    3. 이미 있는 즐겨찾기는 마우스로 끌어다 폴더에 넣으면 됩니다
    4. 폴더를 누르면 그 안의 사이트가 쭉 펼쳐집니다
    ➕ 이렇게 묶어 보세요업무 — 업무포털 · 나이스 · 교육청 홈페이지 · 내 직종에서 매일 쓰는 시스템
    복무·연수 — 복무·취업규칙 자료 · 연수원 홈페이지 · 법제처
    자료·AI — 구글 드라이브 · 제미나이 · 오늘 연수 웹교안
    💡 폴더 하나에 10개 넘게 들어가면 다시 찾기 어려워집니다. 많아지면 폴더 안에 폴더를 하나 더 만드세요.
    📦 만든 즐겨찾기를 다른 계정으로 옮기기 — 개인계정 ↔ 기관계정▾
    즐겨찾기는 계정마다 따로 놉니다. ①에서 나눠 둔 개인계정 프로필과 기관계정 프로필은 서로 즐겨찾기가 안 보여요. 파일 하나로 통째로 옮기면 됩니다.
    1단계 · 원래 계정에서 내보내기
    1. 즐겨찾기가 있는 그 프로필의 크롬을 엽니다
    2. Ctrl+Shift+O — 북마크 관리자가 열립니다
      (또는 ⋮ → 북마크 및 목록 → 북마크 관리자)
    3. 관리자 화면 오른쪽 위 ⋮ → ［북마크 내보내기］
    4. 바탕화면에 저장 — bookmarks_2026….html 파일이 생깁니다
    💡 이 HTML 파일 하나에 폴더 구조까지 통째로 들어 있어요. 메일로 보내거나 USB에 담아도 됩니다.
    2단계 · 받을 계정에서 가져오기
    1. 오른쪽 위 프로필 아이콘을 눌러 받을 계정의 프로필로 전환
    2. 다시 Ctrl+Shift+O → 오른쪽 위 ⋮ → ［북마크 가져오기］
    3. 방금 저장한 HTML 파일을 고르면 끝
    ⚠️ 가져온 즐겨찾기는 「가져온 북마크」 폴더 안에 들어갑니다. 즐겨찾기바에 바로 안 보인다고 당황하지 마세요 — 그 폴더를 열어 마우스로 끌어다 북마크바로 옮기시면 됩니다.
    💡 같은 계정을 다른 PC에서 쓰는 거라면 이 과정이 필요 없어요. 그 PC 크롬에 로그인만 하면 즐겨찾기가 따라옵니다. 이건 계정이 다를 때 쓰는 방법이에요.

💡 꿀팁 — 한글 ‘찾아 바꾸기’로 반복 작업 한 번에 (익명화·일괄수정)

여러 곳에 있는 같은 단어(이름·연도·학교명 등)를 한 번에 바꾸거나, 문서를 익명화할 때 아주 유용해요.

  1. 한글에서 문서 열기 → Ctrl+F2 (또는 Ctrl+H) = 찾아 바꾸기
  2. 찾을 내용에 바꿀 단어, 바꿀 내용에 새 단어 입력 → 모두 바꾸기
  3. 지울 것(전화·주소 등)은 바꿀 내용을 비워두고 모두 바꾸기 → 한 번에 삭제
  4. 파일 → 다른 이름으로 저장 → 파일 형식 PDF — 어디서나 열리는 PDF 완성!
예: 가정통신문·안내문·명단처럼 이름·날짜만 바뀌는 문서를 한 번에 수정!

🖥️ 네 손가락이 아무 반응이 없다면 — 고장이 아니라, 넘어갈 바탕화면이 아직 없어서일 때가 대부분이에요. 가상 데스크톱은 내가 직접 만들어야 생깁니다.
  1. ⊞ Win+Ctrl+D — 새 바탕화면 만들기 (화면이 휙 넘어가면 성공)
  2. 이제 네 손가락으로 좌·우를 쓸어 보세요. 키보드로는 ⊞ Win+Ctrl+←/→
  3. 지금 몇 개인지 보려면 ⊞ Win+Tab — 화면 위에 바탕화면 목록이 뜹니다
  4. 필요 없어지면 ⊞ Win+Ctrl+F4 — 그 바탕화면만 닫히고 창은 옆으로 옮겨져요 (프로그램은 안 꺼집니다)
💡 그래도 제스처가 안 되면 — 설정 → Bluetooth 및 장치 → 터치패드에서 ［세 손가락 제스처］·［네 손가락 제스처］가 켜져 있는지, 동작이 다른 기능으로 바뀌어 있지 않은지 확인하세요. 거기서 내 마음대로 바꿀 수도 있어요.
⚠️ 제스처는 ‘정밀 터치패드’에서만 됩니다. 오래된 노트북이나 제조사 전용 드라이버를 쓰는 기종은 설정을 켜도 안 될 수 있어요. 그럴 땐 키보드 단축키(⊞ Win+Ctrl+←/→)를 쓰시면 똑같이 됩니다.
🚫 터치패드가 아예 안 움직인다면 — 다시 켜는 법▾

① 키보드 한 번 — 가장 흔한 원인
키보드 맨 윗줄 F1~F12 중에 네모에 사선이 그어진 터치패드 그림이 있는 키를 찾으세요. 그 키를 누르거나, Fn을 함께 누르세요.
삼성 갤럭시북·LG 그램은 대개 Fn+F5, 기종에 따라 F6·F7일 수도 있어요.
💡 껐다 켰다 하는 키라 한 번 더 누르면 다시 꺼집니다. 화면에 잠깐 표시가 뜨는 노트북도 있어요.
② 설정에서 켜기
  1. ⊞ Win+I로 설정 열기
  2. Bluetooth 및 장치 → 터치패드
  3. 맨 위 ［터치패드］ 스위치를 «켬»으로
③ 마우스를 꽂으면 꺼지는 설정
마우스를 연결했을 때만 안 된다면 이 설정 때문이에요.
같은 터치패드 화면에서 ［터치패드］ 옆 화살표(∨)를 펼쳐 「마우스가 연결되어 있을 때 터치패드 켜 놓기」에 체크하세요.
⚠️ 마우스도 없어서 클릭을 못 하신다면 — 키보드만으로 갑니다.
⊞ Win을 누르고 터치패드라고 친 뒤 Enter → Tab·방향키로 이동, Space로 스위치를 켭니다.
